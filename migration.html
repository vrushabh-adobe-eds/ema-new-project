Executive Summary

WKND is a compact AEM demo site migrated to Edge Delivery Services with Document Authoring as the content source. A homepage-only crawl reaches ~16 pages; expanding through the Adventures and Magazine listings (plus the gated Members Only articles) surfaces the full 28. Every URL returns HTTP 200 with no redirects, so all 28 are in scope. The inventory is dominated by the repeating Adventure Detail template (16 pages).

Key decisions & notes
  • No sitemap.xml — inventory is crawl-derived; detail pages are only linked from listing pages, so a shallow crawl under-counts.
  • Query-index driven listings — Recent Articles, "Where do you want to go?", Adventures (tabs), Members Only and Contributors all render from helix-query.yaml indexes at runtime (config-only authored rows, no static fallback).
  • Content Fragments → metadata block — Adventure detail pages carry structured spec fields (price, duration, difficulty, group size) → a small adventure-details block.
  • Experience Fragments → EDS fragments — header, footer and shared CTAs.
  • Block consolidation — derived blocks were folded into base blocks as variants (see Block Inventory) so authors pick Base (variant) from one Document Authoring library.

Migration Phases & Sequencing

Ordered by dependency then page-count descending — biggest template ships first after foundations. Each phase is independently deployable and testable.

0Foundationssetup
Extract WKND design tokens (brand yellow, Asar + Source Sans Pro type scale, spacing) into styles/styles.css. Configure the Document Authoring content source and re-host assets. Metric-adjusted fallback fonts to prevent CLS.
1Global Elements — Header & Footerall pages
Site-wide header (nav, search typeahead, mobile slide-in drawer) and footer. Reserve --nav-height eagerly to avoid hydrate shift.
2Homepage1 page
Validate the core block set — carousel (hero, query-index driven), columns (featured), hero (promo), article-list grids — and design tokens.
3Adventure Detail — highest volume16 pages
Build the repeating detail template (breadcrumb + adventure-details spec block + tabs + gallery carousel) and bulk-import all 16. Largest single win.
4Magazine Article5 pages
Article layout with rich text, byline (article-author) and a query-index related-articles list. Includes the 2 gated Members Only articles.
5Listings & Content3 pages
Adventures listing (article-list tabs + category filter + search index), Magazine listing (+ Members Only), and About Us (contributors split by type). All query-index driven.
6FAQs1 page
Accordion (faq) variant, sheet-driven from /us/en/faqs/faq-data.json. Two-column "Need more help?" layout.
7Block Consolidation & Libraryrefactor
Fold derived blocks into base + variant (carousel / hero / columns / cards / accordion / tabs), keeping query-index blocks separate. Publish a Document Authoring block library so authors insert Base (variant) from one panel.
8Cleanup & QAfinal
Wire the search indexes (helix-query.yaml), and a final performance + accessibility QA pass (Lighthouse ~100 mobile + desktop, CWV in "good").
